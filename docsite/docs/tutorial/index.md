# Tutorial overview

## Prerequisites

For the live demonstration, start with an existing installation, downloaded
model weights, and prepared micrograph/particle inputs. The
[demo guide](../demo.md) explains how to run the app and site together and
links the five presentation segments in order. Each workflow states its
additional inputs and resource requirements.

    added. Use existing processed data for the demo.
