# cryoFILTER tutorial

Learn to identify contamination and filter particle picks with the cryoFILTER
browser app.

[Open the demo walkthrough](demo.md){ .md-button .md-button--primary }

## Five workflows to try

1. [Run from completed CryoSPARC inputs](tutorial/cryosparc.md).
2. [Generate masks with inference alone](tutorial/inference.md).
3. [Filter particle picks using those masks](tutorial/filter-picks.md).
4. [Follow motion correction with OTF](tutorial/otf.md).
5. [Annotate micrographs](tutorial/annotation.md) and
   [fine-tune from saved annotations](tutorial/fine-tuning.md).

!!! note "Working tutorial"
    The demo guides are ready to rehearse with your existing inputs. Screenshots,
    the reproducible EMPIAR-10532 subset, and measured examples are still to come.
    Remaining setup and reference pages are marked where they are in preparation.
